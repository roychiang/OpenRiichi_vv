# WebGL Riichi Mahjong - Epic 與 User Story

## Epic 1: 核心遊戲移植 (Core Game Porting)
將 OpenRiichi 核心體驗移植至 WebGL。

-   **US 1.1**: 作為玩家，我希望能在瀏覽器中看到 3D 麻將桌和牌山，以便進行遊戲。
-   **US 1.2**: 作為玩家，我希望能夠使用滑鼠點擊或拖牌來進行切牌操作。
-   **US 1.3**: 作為玩家，我希望能看到吃、碰、槓、立直、胡牌的 UI 按鈕，並在適當時機觸發。
-   **US 1.4**: 作為玩家，我希望遊戲視角可以自由旋轉或切換（俯視/3D），以適應我的習慣。

## Epic 2: Viverse 整合 (Viverse Integration)
整合 Viverse 生態系統功能。

-   **US 2.1**: 作為用戶，我希望能使用 Viverse 帳號一鍵登入，無需重新註冊。
-   **US 2.2**: 作為用戶，我希望我的 Viverse 頭像 (Avatar) 或頭像圖示能顯示在遊戲內的玩家資訊欄。
-   **US 2.3**: 作為用戶，我希望我的遊戲戰績和籌碼數據能被永久保存，換設備也能同步。

## Epic 3: 多人連線與大廳 (Multiplayer & Lobby)
建立多人遊戲的基礎設施。

-   **US 3.1**: 作為玩家，我希望進入遊戲後先看到大廳 (Lobby)，列出當前所有可加入的牌桌。
-   **US 3.2**: 作為玩家，我希望能自己開設新桌，並設定是否公開。
-   **US 3.3**: 作為桌長，我希望能手動點擊「開始」來啟動遊戲。
-   **US 3.4**: 作為玩家，當牌桌滿 4 人後，我希望系統倒數 20 秒自動開始，避免久候。

## Epic 4: AI 補位與託管 (AI & Bots)
確保遊戲隨時可玩，不被缺人打斷。

-   **US 4.1**: 作為桌長，當等待時間過長且未滿 4 人時，我希望系統能自動加入 AI Bot 補足人數。
-   **US 4.2**: 作為玩家，當同桌有人斷線或離開時，我希望 AI Bot 能立即接手其位置，讓牌局繼續。
-   **US 4.3**: 作為玩家，我希望能分辨出對手是真人還是 AI Bot（例如透過名稱或圖標標示）。

## Epic 5: 社交互動 (Social Features)
增強玩家間的溝通。

-   **US 5.1**: 作為玩家，我希望在大廳能有一個公共聊天室，與所有在線玩家交流。
-   **US 5.2**: 作為玩家，我希望在牌桌內能與同桌玩家進行文字聊天。
-   **US 5.3**: 作為玩家，我希望能開啟語音麥克風，與同桌好友進行即時語音通話。
-   **US 5.4**: 作為玩家，我希望能屏蔽特定玩家的語音或文字，以避免騷擾。

## Epic 6: 經濟與排行榜 (Economy & Leaderboard)
提供遊戲動力與成就感。

-   **US 6.1**: 作為新玩家，我希望能獲得 5,000 初始籌碼作為啟動資金。
-   **US 6.2**: 作為玩家，我希望每局結束後，系統能根據排名自動結算籌碼增減。
-   **US 6.3**: 作為玩家，我希望能在主選單查看「役滿排行榜」和「對局數排行榜」，看看誰是高手。
-   **US 6.4**: 作為玩家，當我籌碼歸零時，我希望能領取每日救濟金，以便繼續遊玩。

## Epic 7: LLM Agent 擴展 (LLM Integration)
讓開發者與 AI 愛好者參與。

-   **US 7.1**: 作為開發者，我希望有一個標準的 API 接口，讓我能接入自己訓練的 LLM 麻將模型。
-   **US 7.2**: 作為玩家，我希望能選擇特定的 LLM Agent 作為對手，挑戰不同的 AI 風格。
