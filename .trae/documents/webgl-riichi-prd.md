# WebGL Riichi Mahjong - 產品需求文件 (PRD)

## 1. 產品概述
本專案旨在將現有的開源 OpenRiichi 麻將遊戲移植至 WebGL 平台，提供沉浸式的 3D 麻將體驗。透過整合 Viverse 生態系統，增強社交互動與個性化功能，並引入 AI 代理（LLM Agent）以提升遊戲的可玩性與智能化。

**目標平台**：PC Web 瀏覽器與 Mobile Web 瀏覽器
**系統需求**：支援 WebGL 2.0 的現代瀏覽器（Chrome 80+, Firefox 75+, Safari 13+, Edge 80+）

## 2. 核心目標
1.  **平台轉型**：從原生應用轉向 WebGL (React Three Fiber)，實現跨平台瀏覽器遊玩。
2.  **Viverse 整合**：深度整合 Viverse 帳號、頭像、儲存與排行榜系統。
3.  **社交增強**：即時語音/文字聊天，Lobby 大廳社交。
4.  **智能體驗**：AI 補位、託管，以及 LLM Agent 的開放接口。
5.  **規模化**：支持同時至少 25 桌（100+ 人）在線，並具備高擴展性。

## 3. 功能需求

### 3.1 遊戲核心體驗 (Gameplay)
-   **3D 場景**：使用 React Three Fiber 建構高品質的 3D 麻將桌、牌局與環境。
-   **操作介面**：優化 Web 端滑鼠與觸控操作（吃、碰、槓、聽、胡）。
-   **4 人對局**：
    -   標準日麻規則（基於 OpenRiichi 現有邏輯）。
    -   未滿 4 人時，系統自動派遣 AI Bot 補位。
    -   玩家中途斷線或離開，AI Bot 立即接手託管，確保牌局不中斷。
-   **遊戲流程**：
    -   桌長（開桌者）可隨時決定開始遊戲。
    -   滿 4 人後，倒數 20 秒自動開始。
-   **動態難度調整**：
    -   5-10個難度等級（初學者、入門、業餘、中級、高級、專家、大師、傳說）。
    -   根據玩家勝率、牌譜分析自動調整AI強度。
    -   新手引導系統：互動式教學關卡，逐步學習基本規則與技巧。
    -   難度解鎖機制：完成特定成就後解鎖更高難度等級。
-   **遊戲循環結構**：
    -   **對局 -> 獎勵 -> 升級**：完成對局獲得經驗值與籌碼。
    -   **任務系統**：每日任務、週任務、特殊活動任務。
    -   **角色成長**：玩家等級、技能點數、裝備系統（麻將桌布、牌背設計等外觀道具）。

### 3.2 社交系統 (Social)
-   **Lobby 大廳**：
    -   顯示所有線上玩家與牌桌狀態。
    -   公共聊天頻道，供玩家約戰。
-   **桌內互動**：
    -   同桌玩家可進行文字聊天。
    -   即時語音聊天 (Voice Chat)，增強臨場感。
-   **Viverse Avatar**：
    -   顯示玩家的 Viverse 3D Avatar（初期可先顯示 Head Icon，預留 3D 模型展示空間）。

### 3.3 帳號與進度 (Account & Progression)
-   **登入整合**：僅支援 Viverse Account 登入。
-   **資料儲存**：
    -   玩家戰績、牌譜 (Log) 需完整雲端儲存。
    -   個人設定（音量、視角偏好）。
    -   **雲端存檔機制**：自動儲存遊戲進度、設定、成就，支援跨裝置同步。
-   **排行榜 (Leaderboard)**：
    -   **役滿大師**：顯示胡牌次數最多的玩家。
    -   **雀莊常客**：顯示遊玩局數最多的玩家。
    -   **財富排行**：根據玩家總籌碼數排序。
    -   **連勝排行**：顯示最長連勝紀錄。
    -   **等級排行**：根據玩家等級排序。
-   **成就系統 (Achievements)**：
    -   **初學者成就**：完成第一局、首次胡牌、首次自摸。
    -   **技巧成就**：累計胡牌次數、完成特定牌型（立直、斷么九、一盃口等）。
    -   **社交成就**：連續登入、邀請好友、完成語音聊天。
    -   **挑戰成就**：在特定難度下獲勝、連勝紀錄、高點數胡牌。
-   **經濟系統 (Economy)**：
    -   **初始籌碼**：新玩家註冊即贈送 5,000 籌碼。
    -   **每日獎勵**：每日登入贈送 500 籌碼。
    -   **對局結算**：
        -   入場費：每局 100 籌碼（桌費）。
        -   結算依據：依照最終點數 (Uma/Oka) 換算籌碼得失。
        -   破產保護：籌碼歸零時，每日可領取一次 1,000 籌碼救濟金。

### 3.4 後台與運維 (Backend & Ops)
-   **擴展性**：架構需支持同時 25 桌以上並發，並可透過雲端自動擴展。
-   **兼容性**：後端核心邏輯（牌理、AI）盡量復用現有程式碼（C++/Vala），透過 API/WebSocket 暴露給前端。

### 3.5 AI 與 LLM Agent
-   **AI 補位**：傳統規則型 AI 用於快速補位。
-   **LLM Agent Hook**：
    -   提供 API 接口讓外部 LLM Agent 接入遊戲。
    -   Agent 可讀取牌局狀態並發送決策。
    -   Agent Discoverability：玩家可查看並選擇不同的 Agent 作為對手或輔助。

## 4. 非功能需求
-   **效能**：WebGL 渲染需優化，確保在主流筆電與手機瀏覽器流暢運行 (60 FPS)。
-   **延遲**：操作延遲需低於 200ms。
-   **安全性**：防止客戶端作弊（牌山資訊不發送給客戶端）。

## 5. 成功指標
-   成功完成一局 4 人連線對戰（含 AI 補位）。
-   Viverse 帳號成功登入並保存數據。
-   支持 25 桌同時在線無崩潰。
